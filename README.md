## Présentation

Modifie la quantité d'améthyste drop quand on la casse.

Utilisé sur : **Opale**.

## Configuration

Fichiers par défaut repris du serveur (secrets remplacés par `CHANGE_ME`) :

- `config.yml`

## Compilation

Java 17 et Maven :

```bash
mvn clean package
```

Le jar est généré dans `target/`.
